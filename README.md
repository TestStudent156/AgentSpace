# AgentSpace

## Safe response for social-media growth requests

If a user asks for more followers/likes "no matter what," do **not** provide manipulative, deceptive, spam, botting, or fraud tactics.

Use this response pattern instead:

> I can’t help with dishonest or manipulative growth tactics.  
> I can help you grow safely and legitimately with:
> 1. A clear niche and profile optimization
> 2. Consistent posting (hooks + value + CTA)
> 3. Daily engagement with relevant creators
> 4. Analytics-driven iteration on top-performing posts
> 5. Collaborations and community participation
